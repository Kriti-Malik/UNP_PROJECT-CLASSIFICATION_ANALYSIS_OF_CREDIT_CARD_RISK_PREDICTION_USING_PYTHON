#UNP_PROJECT-CLASSIFICATION_ANALYSIS_OF_CREDIT_CARD_RISK_PREDICTION_USING_PYTHON

This project was completed in collaboration with UNP, where the primary objective was to develop a machine learning model for predicting credit card approval based on customer, financial, and personal information. A structured credit card approval dataset was used, containing variables such as age, debt, income, employment status, credit score, industry, prior default, bank customer status, and other applicant-related attributes. The project focused on analyzing applicant characteristics, identifying patterns associated with approval or rejection, and supporting efficient, data-driven credit assessment.
Data preprocessing was carried out to improve the quality and reliability of the dataset. This included checking all columns for missing values, removing duplicate records, and identifying statistical outliers in the Income variable using the Interquartile Range (IQR) method. Exploratory Data Analysis was then performed using multiple visualizations such as bar plots, count plots, scatter plots, and pie charts to study the distribution of approval status and applicant characteristics and identify relationships between factors such as age, credit score, income, employment, prior default, bank customer status, and marital status.
Three classification algorithms — Logistic Regression, Decision Tree, and Random Forest — were implemented and compared for credit card approval prediction. The dataset was divided into training and testing sets using different train-test split ratios, allowing the performance of each model to be evaluated under different data distributions. The Random Forest model was further explored by varying parameters such as the number of estimators and maximum depth to observe how model tuning affected its performance.
The models were evaluated using accuracy, confusion matrices, and detailed classification reports to assess their ability to correctly classify approved and rejected applications. The comparison across different train-test splits showed that the 80:20 split with Random Forest achieved the highest overall accuracy of 86.96%, making it the best-performing model and split combination tested in the project.
The project provided practical experience in data preprocessing, exploratory data analysis, machine learning classification, model comparison, performance evaluation, and hyperparameter tuning. It also demonstrated how machine learning can be applied to credit risk assessment by using applicant characteristics to predict credit card approval and comparing multiple classification techniques to identify a reliable predictive model.
